
Path Control Using Policy-Based Routing (PBR)
=============================================

OBJECTIVE:
----------
Demonstrate the use of Policy-Based Routing (PBR) to control path selection
on the given topology.

ASCII Topology:
---------------
         +--------+         
         |   R2   |         
         |s3/0 s3/1|         
         +--------+         
          /      \         
         /        \        
        /          \       
+--------+       +--------+       +--------+
|   R1   |-------|   R3   |-------|   R4   |
|s3/0 s3/1|       |s3/0/1/2|       |s3/0   |
+--------+       +--------+       +--------+
     \________________/

LINK IP ADDRESSES:
------------------
- R1-R2 (s3/0 - s3/0): 10.0.12.0/30
- R1-R3 (s3/1 - s3/0): 10.0.13.0/30
- R2-R3 (s3/1 - s3/1): 10.0.23.0/30
- R3-R4 (s3/2 - s3/0): 10.0.34.0/30

=====================================
R1 CONFIGURATION (Policy-Based Routing)
=====================================
hostname R1

interface s3/0
 ip address 10.0.12.1 255.255.255.252
 clock rate 64000
 no shutdown

interface s3/1
 ip address 10.0.13.1 255.255.255.252
 clock rate 64000
 no shutdown

access-list 100 permit ip 192.168.1.0 0.0.0.255 any

route-map PBR permit 10
 match ip address 100
 set ip next-hop 10.0.13.2

interface s3/1
 ip policy route-map PBR

ip route 0.0.0.0 0.0.0.0 10.0.12.2
