
VRF (Virtual Routing and Forwarding) Configuration Simulation
==============================================================

Objective:
----------
Simulate Virtual Routing and Forwarding (VRF) on a Cisco router topology
to provide routing table separation for different customers or departments.

ASCII Topology:
---------------
    +---------+            +---------+             +---------+            +---------+            +---------+
    |   R4    |            |   R1    |             |   R2    |            |   R3    |            |   R5    |
    | f0/0    |------------| f1/0    |-------------| f0/0    |------------| f0/0    |------------| f0/0    |
    +---------+            | f0/0    |             | f1/0    |            | f1/0    |            +---------+
                           +---------+             +---------+            +---------+

Interface Mapping (Sample IP Addresses):
----------------------------------------
R1:
 - f0/0: 10.0.12.1/30 (to R2)
 - f1/0: 10.0.14.1/30 (to R4)

R2:
 - f0/0: 10.0.12.2/30 (to R1)
 - f1/0: 10.0.23.1/30 (to R3)

R3:
 - f0/0: 10.0.23.2/30 (to R2)
 - f1/0: 10.0.35.1/30 (to R5)

R4:
 - f0/0: 10.0.14.2/30 (to R1)

R5:
 - f0/0: 10.0.35.2/30 (to R3)

============================
 STEP 1: CONFIGURATION ON R1
============================
conf t

! Create VRFs
ip vrf RED
 rd 1:1
!
ip vrf BLUE
 rd 2:2

! Assign Interfaces to VRFs
interface f0/0
 ip vrf forwarding RED
 ip address 10.0.12.1 255.255.255.252
 no shutdown
exit

interface f1/0
 ip vrf forwarding BLUE
 ip address 10.0.14.1 255.255.255.252
 no shutdown
exit

! Configure static routes in VRFs
ip route vrf RED 10.0.23.0 255.255.255.252 10.0.12.2
ip route vrf BLUE 10.0.35.0 255.255.255.252 10.0.14.2

end
write memory

============================
 STEP 2: CONFIGURATION ON R2
============================
conf t
ip vrf RED
 rd 1:1
!
interface f0/0
 ip vrf forwarding RED
 ip address 10.0.12.2 255.255.255.252
 no shutdown
!
interface f1/0
 ip vrf forwarding RED
 ip address 10.0.23.1 255.255.255.252
 no shutdown
exit
end

============================
 STEP 3: CONFIGURATION ON R3
============================
conf t
ip vrf RED
 rd 1:1
!
ip vrf BLUE
 rd 2:2
!
interface f0/0
 ip vrf forwarding RED
 ip address 10.0.23.2 255.255.255.252
 no shutdown
!
interface f1/0
 ip vrf forwarding BLUE
 ip address 10.0.35.1 255.255.255.252
 no shutdown
!
ip route vrf RED 10.0.12.0 255.255.255.252 10.0.23.1
ip route vrf BLUE 10.0.14.0 255.255.255.252 10.0.35.2
end

exit
end

R5:
----

end

============================
 VERIFICATION COMMANDS
============================

# Show VRF configurations
show ip vrf
show ip interface brief
show running-config | section interface

# Test Connectivity
ping vrf RED 10.0.23.2
ping vrf BLUE 10.0.35.2
